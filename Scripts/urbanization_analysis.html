Goal

The goal of this analysis is to explore predictors of number of cases of Mycoplasma in the house finch epizootic simulations I’ve done. The predictors I will investigate are:

  • Time
  • Distance from index case
  • Urbanization
  • Temperature seasonality
  • Mean annual temperature

To measure this, I will need to go from 1994 (the start of the outbreak) to 2016 (the end of the outbreak) and assemble data frames of number of cases, then pair these data with calculated distances from the index case and extracts from the raster of spatial predictors. I will then use a regression model to investigate the relationship between the predictors and number of cases.

Environmental predictors

To get the environmental predictors, I will need to extract values from the rasters of urbanization, temperature seasonality, and mean annual temperature for each cell in the region.

Code 
col_names <- 1:19 %>%
  as.character() %>%
  map(~ paste0("bio", .)) %>%
  append("urban") %>%
  flatten_chr()
files2 <- list.files(
  "~/Documents/Very_Large_Data/predictors/CHELSA",
  pattern = "^predictors_.+",
  full.names = T
) %>%
  keep(str_detect, pattern = "\\.grd$") %>%
  .[55:77] |>
  set_names(years)
extracted <- dt |>
  group_by(Year) |>
  group_split() |>
  map(~ select(.x, x, y)) |>
  future_map2(
    files2,
    function(p, f) {
      r <- rast(f)
      terra::extract(r, p, ID = F)
    },
    .options = furrr_options(seed = T)
  ) %>%
  map(~ set_names(., col_names)) %>%
  list_rbind(names_to = "Year") |> 
  select(bio1, bio4, urban) |> 
  bind_cols(dt)

Intriguingly, urbanization is still a meaningful predictor even when we control for population size, which means that the effect of urbanization goes beyond simply increasing the finch population size. Mechanistically given how the model works, this has to be about the density-dependent dispersal, in which dispersal depends on the saturation of carrying capacity (N/K) in a locale.
