Preliminary results from process-explicit models of the MG outbreak in house finches

Author

July Pilowsky

1. What is this all about?

These are process-explicit models (Pilowsky et al. 2022) of the MG outbreak in house finches using the epizootic package, which I created for modeling wildlife disease outbreaks. This is a powerful tool for understanding processes and spatially-explicit disease dynamics, because unlike other approaches, it can give spatiotemporally explicit values for population size, new infections, and other key metrics. It can also be used to infer uncertain and unobserved parameters, such as the number of house finches in the founder population in New York. However, we must keep in mind the following limitations:

  • The models are only as good as the validation data.
  • The models assume that the characteristics of Mycoplasma gallisepticum do not change over time, which we know to be false (Fleming-Davies et al. 2018).
  • The models assume that there are no regional differences in the characteristics of M. gallisepticum or house finches, which we also know to be false (Dhondt et al. 2006).

2. The validation data

We used the following data for model validation:

  • Are there finches in Washington DC in 1994? This is crucial because this is the time and place where the Mycoplasma gallisepticum outbreak first occurred. If there are no finches there, there can’t be an outbreak. The subsequent metrics are conditioned on whether the simulation meets this criterion. All simulations that fail are excluded.
  • Mycoplasma presence. There are 90 locations where Project FeederWatch spotted infected finches every year for years on end (median: 16 consecutive years). This score measures whether the simulations can replicate that persistence. A lower score indicates a better ability to replicate persistence.
  • First arrival of Haemorhous. I estimated the first arrival of the house finch in parts of its invasive range based on sightings from the Breeding Bird Survey, with uncertainty due to incomplete observation. I assigned a penalty for the simulated date of first arrival falling outside the estimated range. I have these estimates for 14,850 locations.

It is important to note that I started out with more validation data than this. I narrowed down to these metrics using abctools::selectsumm, which picks validation metrics from a set based on which ones parsimoniously inform the posterior distribution the most. This means I can justifiably try out other validation data if it seems like there are problems with the selected metrics.

Let us have a look at the performance of the final round of simulation modeling on these metrics.

validation_metrics <- bind_rows(
  round1_metrics,
  round2_metrics,
  round3a_metrics,
  selected_metrics
) |>
  mutate(
    Round = factor(c(rep("1", 10000), rep("2", 10000), rep("3", 10000), rep("Selected", 32)))
  ) |>

validation_metrics |>
  filter(Round!="Selected") |>
  tidyplot(x = Round, fill = dc) |>
  add_barstack_absolute() |>
  adjust_y_axis_title("Count") |>
  adjust_x_axis_title("Simulation Round") |>
  adjust_colors(new_colors = paletteer_d("nbapalettes::nets")) |>
  adjust_legend_title("Finches in DC in 1994")

There were 10,000 simulations in each round of modeling, so performance on this metric did not monotonically improve. This is more or less expected; I could not use this metric for validation by Approximate Bayesian Computation (ABC) because it is binary, so it was used as a pre-filter for ABC, so ABC could not optimize for it.

Now we will examine the other two validation metrics, Mycoplasma presence and first arrival of Haemorhous, which are only calculated for simulations that had finches in DC in 1994.

Code 
validation_metrics |>
  pivot_longer(
    c(mg_presence, hm_arrival),
    values_to = "Value",
    names_to = "Metric"
  ) |>
  filter(!is.na(Value)) |>
  mutate(Metric = recode(
    Metric,
    mg_presence = "MG persistence",
    hm_arrival = "Finch arrival"
  )) |>
  tidyplot(x = Value, fill = Round) |>
  add_histogram(bins = 30, alpha = 0.5, position = "identity") |>
  adjust_y_axis_title("Count") |>
  adjust_colors(new_colors = paletteer_d("PNWColors::Sunset2", 4)) |> 
  split_plot(by = Metric, scales = "free_x") |>
  adjust_y_axis(
    transform = transform_pseudo_log(),
    force_continuous = TRUE,
    breaks = c(0, 10, 100, 1000),
    labels = label_number(big.mark = ",", accuracy = 1)
  )

Lower values are better for both, so there’s improvement on both metrics as we proceed through rounds 1, 2 and 3. However, first arrival of Haemorhous is still pretty far off from zero, the perfect score. We decided to stop modeling at this stage because the Bayes factors indicated that the posterior distributions had stabilized, and posterior predictive checks showed that the predictive power of the models could improve no further, at least with these validation metrics. The fact that first arrival of Haemorhous remained far from zero indicates that there is something about the assumptions of the model that makes it impossible to accurately recreate the first arrival of house finches to various regions.

At this point, what I did was take the top 1% of models from round 3 based on these three validation metrics, and then created a weighted ensemble mean of these simulations. I will refer to this as the validated ensemble model.

3. Visualizing the validated ensemble model

I find that the easiest way to visualize the outbreak dynamics is using animations.

3a. Total population size

Let’s start with an animation of total population size of house finches.

Code 
abc31_processed <- process_sims(selected_samples_3, abc31$weights, here("Data/Output/Round3a"))
total_population_size <- abc31_processed$total_population
animate_sim(total_population_size, region, years = 1940:2016)

We can see here the effect of the outbreak on population size. According to the literature, the MG outbreak roughly halved population densities of house finches (Hochachka et al. 2021), and in this animation, the population seems to decline by more than half after the arrival of MG. It is important to note that I did not use finch trends in population size as validation metrics, so there was nothing selecting for correct population size trends. As noted above, I chose validation metrics based on which combination of metrics informed the posterior distributions the most. I could try running the simulations again using validation metrics chosen a different way.

3b. Prevalence

Here is an animation of prevalence of MG in the house finch population.

Code 
prevalence <- abc31_processed$prevalence
animate_sim(prevalence, region, years = 1994:2016, burn_in = 111)

The prevalence definitely gets too high to be realistic in this simulation; it is rare for a deadly outbreak like this one to reach 100% prevalence, let alone over such a large geographical extent. The validation metric that could control for this is spatiotemporal point prevalence, based on data points on prevalence in the literature, which I did not use here. As mentioned above, I chose my validation metrics based on which subset of them most informed the posterior distributions, but I could try re-running the simulations using validation metrics chosen a different way.

4. Urbanization analysis

A question I was really interested in answering with this model was whether urbanization really increases cases of MG, as many papers on MG have supposed based on date of first arrival of the outbreak in rural vs. urban areas. Here I fit a regression model to the validated ensemble model to investigate the relationship between urbanization and number of MG cases, controlling for other factors.

Intriguingly, urbanization is still a meaningful predictor of total MG cases even when we control for population size, which means that the effect of urbanization goes beyond simply increasing the finch population size. The partial dependence profile indicates that this is a threshold effect, in which having zero urbanized land cover is associated with lower cases, but any amount of urbanized land cover is associated with higher cases, and then the effect levels off.

I would advise caution in taking the exact size of the effect to heart (which is shown in the partial dependence profile as an average increase of 350 cases per 46 km x 46 km grid cell as proportion of urban land goes above 0) due to the excessively high prevalence in the validated ensemble model.
